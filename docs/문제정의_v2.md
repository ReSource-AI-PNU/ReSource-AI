## 1. 한 줄 정의

**정부가 한 해 10곳에만 해 주는 사업장 폐플라스틱 순환 진단을, AI 에이전트로 모든 중소 제조기업에 제공한다.**

부산·경남의 고무·플라스틱 제조 중소기업은 공장에서 나오는 폐플라스틱 흐름의 성질과 갈 곳을 모른 채, "가장 싼 소각"을 기본값으로 내보낸다. Re:Source AI는 공장의 폐플라스틱을 흐름별로 진단해 재투입·매각·묶음 매각·열분해·소각 중 갈 곳을 정해 주고, 이행 계획과 지원사업 신청, 견적 요청까지 이어 준다.

## 2. 대회 주제와의 연결

| 대회 주제 | 우리 답 |
|---|---|
| 산업현장의 **모든 기업**이 | 정부 진단(10곳)과 지원사업(연 1,000톤 이상 배출 기업)이 닿지 않는 중소기업 |
| **AI를 활용하여** | 전문가 1:1 기술진단 절차를 에이전트 6개가 나눠 수행한다 |
| 폐기물과 부산물에서 | 공장 한 곳의 폐플라스틱 흐름 전체(공정 부산물 + 공장이 쓰고 버린 포장재) |
| **더 많은 경제적·환경적 가치** | 소각 처리비를 매각 수익·원료 절감으로 바꾸고, 회피 탄소를 계산한다 |

## 3. 누가, 언제, 무엇을 잃나

- **누가**: 부산·경남 고무·플라스틱 제조 중소기업(연 1,000톤 미만 배출)의 폐기물 담당자. 대부분 총무·생산·품질 담당이 겸직한다.
- **언제**: 처리업체가 단가 인상을 통보할 때, 연간 처리 계획을 세울 때, 원청이 탄소·재활용 데이터를 요구할 때.
- **무엇을 잃나**: 폐플라스틱 흐름마다 갈 수 있는 더 나은 경로(재투입, 매각, 묶음 매각, 열분해)가 있는데, 흐름을 구분하지 않고 혼합 소각으로 내보내 **처리비, 원료 가치, 탄소**를 함께 잃는다.

## 7. 왜 지금인가

- 처리비가 오르고 매립지가 찬다(근거 7).
- PE·PP 용기와 비닐류에 재생원료 목표율(10~30%) 도입이 예고됐고(2026.4 탈플라스틱 순환경제 전환 추진계획), 재생원료 품질·함량 인증제도 예고됐다. 고품질 사용 후 원료 수요가 커진다.
- 원청의 탄소·재활용 데이터 요구가 협력사까지 내려온다(근거 8).
- 정부가 진단 절차를 직접 시작해, 해법의 모양이 검증되었다(근거 3).

## 8. 서비스 흐름 v2

정부 기술진단 절차와 대회 6단계를 겹친다. 단위가 "사진 한 장"에서 **"공장의 폐플라스틱 흐름 여러 개"**로 바뀐다.

| 대회 6단계 | 정부 진단 절차 | 에이전트가 하는 일 |
|---|---|---|
| ① 식별·분류 | 종류·성상 | 공정별 흐름을 찍으면 재질, 단일 재질 여부, 오염, 색 혼합, **PIR(공정 부산물) / PCR(공장이 쓰고 버린 포장재)** 을 판정한다 |
| ② 가능성 판단 | 공정별 발생량 | 흐름마다 최적 경로를 고른다: 공정 재투입 / 매각 / 묶음 매각 / 열분해 / 소각 불가피. 흐름별 발생량은 되묻는다 |
| ③ 규정 검토 | (이행 방안의 법적 요건) | 순환자원 지정 품목, PCR 출처 증빙, 단지 내 공동 수집·운반 요건, 위탁 업체 허가 범위를 조항과 함께 확인한다 |
| ④ 업종·기업 탐색 | 주변 재활용시설 여건 | 주변 재활용시설과 수요처를 찾고, 양이 적은 흐름(포장 필름 등)은 같은 단지 기업과 묶는다 |
| ⑤ 비용·탄소 비교 | (이행 방안의 효과) | 현행 "전부 소각" 대비 흐름별·공장 전체 손익과 회피 탄소를 계산한다 |
| ⑥ 최적안 제안 | 이행 방안 + 지원사업 연계 | 공장 이행 계획서, 정부 지원사업 신청 초안, 견적 요청서를 만든다. 외부 발송은 담당자 승인 후 |

재학습 루프와 현장 지식 카드는 그대로 둔다. 판정을 고친 기록과 업체의 실제 매입 결과가 다음 진단을 더 정확하게 만든다.

## 9. 대표 시연 장면: 사출 공장 한 곳의 네 흐름

녹산국가산업단지의 PP 사출 공장 "(주)한빛정밀"(가상)이 지금은 폐플라스틱을 모두 혼합 소각으로 내보낸다고 가정한다. 숫자는 시연용 가정값이며 인터뷰로 바꾼다.

| 흐름 | 성질 | AI가 고른 경로 | 바뀌는 것 |
|---|---|---|---|
| 스프루·러너 | PP 단일, 깨끗, PIR | 분쇄 후 공정 재투입 | 신재 구매 절감 |
| 불량 성형품 | PP 단일, 라벨·이물 일부, PIR | 이물 제거 후 재생원료 업체 매각 | 처리비 → 매각 수익 |
| 퍼지 덩어리·색 혼합 | PP+ABS 혼합, PIR | 열분해 업체 위탁 (기계적 재활용 불가) | 소각 대비 처리비·탄소 감소 |
| 원자재 포장재(스트레치 필름, PP 마대) | PE·PP 단일, **공장이 쓰고 버린 것(PCR)** | 단지 내 3개사 묶음 순회 수거 → PCR 재생원료 | 소량이라 못 팔던 것을 묶어서 판다. 출처 증빙이 가치를 만든다 |

발표의 절정은 "전부 소각"이던 공장 한 곳의 손익이 흐름별로 나뉘며 뒤집히는 장면이다.

## 10. 묶음 수거의 기본값: 순회 수거 계약

- 산업단지 자격(시행규칙 제21조제1항제7호의2)으로 공동처리를 하면, 대표자가 배출자 신고를 대신할 수 없어 각 회사가 직접 신고해야 한다. 공동 보관은 금지되고, 위탁 업체가 사업장을 순회하며 사업장마다 배출량을 확인받아야 한다.
- 그래서 기본값은 **각 회사가 같은 허가 업체와 따로 계약하는 순회 수거**다. 플랫폼은 일정 조율, 물량을 모은 단가 협상, 비용 분담만 맡는다. 책임이 섞이지 않고 신고 부담도 늘지 않는다.
- 공동처리 신고는 선택 기능으로 둔다. 대표자 대행이 필요하면 제9호(소량 배출) 인정 경로로 신고서 초안을 만든다.
- 신뢰 장치: 사업장별 계량과 사진 기록, 다른 회사에는 배출량을 숨기고 분담 비율만 공개, 기준 미달 물량은 그 회사 것만 받지 않는다.

## 11. 수익 모델 (가설)

1. **B2G**: 스마트그린산단 자원순환 플랫폼 예산, 순환경제 산단 사업. 산단 관리기관·지자체가 지역 중소기업에 무료로 제공하는 형태.
2. **성과 기반 수수료**: 실제로 줄어든 처리비와 늘어난 매각 수익의 일부. 중소기업은 초기 비용이 없다.
3. **협력사 데이터 리포트**: 원청의 협력사 ESG·탄소 데이터 요구에 맞춘 재활용·회피 탄소 리포트.

직접 수거 차량과 처리 자산을 갖지 않는다. 유사 플랫폼(Rubicon 매출총이익률 6.1%, 2024년 상장폐지)이 운영비로 적자를 쌓은 구조를 피한다.

## 12. 검증할 가정과 인터뷰 질문

| 가정 | 확인 방법 |
|---|---|
| 중소 사출·압출 공장에서 혼합 소각되는 흐름이 실제로 있다(재투입·매각되는 깨끗한 스크랩 외에) | 녹산 배출 기업 3~5곳: 공정별 폐플라스틱 흐름과 현재 처리 방법, 톤당 또는 차량당 처리비 |
| 흐름별로 나누면 경로가 달라진다 | 재활용·열분해 업체 2~3곳: 재질·오염별 매입 조건, 최소 물량 |
| 공장 포장재(필름·마대)가 PCR로 인정된다 | 환경부 또는 한국환경공단 질의, 재생원료 인증 시범사업 담당 |
| 강서구청이 녹산 소량 배출 업체를 시행규칙 제21조제1항제9호로 인정한다 | 강서구청 환경 담당 |
| 성과 기반 수수료를 낼 의향이 있다 | 배출 기업: 처리비가 몇 % 줄면 참여할지, 그중 몇 %를 수수료로 낼지 |
| 산단 관리기관이 구매한다 | 산단공 부산지역본부: 스마트그린산단·순환경제 사업의 플랫폼 구매 경로와 예산 |
