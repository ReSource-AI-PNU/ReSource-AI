# 목업 디자인 감사와 v2 개선 내역

작성일: 2026-11-05
방법: gstack `/design-review` 스킬의 디자인 감사 체크리스트(10개 분류, 약 80개 항목)를 v1 목업에 적용하고, 걸린 항목을 v2에서 수정했다. 차트 색은 dataviz 스킬 팔레트를 유지했다.

파일
- v1: `resource-ai-mockup-v1.html` (감사 대상)
- v2: `resource-ai-mockup.html` (개선본)

## 걸린 항목과 수정

| 분류 | v1 문제 | v2 수정 |
|---|---|---|
| AI 슬롭 | 본문 글꼴 system-ui 기본값 | Pretendard 가변 글꼴. CDN 실패 시 시스템 글꼴로 폴백 |
| AI 슬롭 | 이모지를 아이콘으로 사용 (📷 ✔ ⚠ 📄 🔔 📅 🏭) | 인라인 SVG 심볼 17종으로 교체 |
| AI 슬롭 | 로고 그라데이션 | 단색 마크 |
| AI 슬롭 | 안내 박스의 색 왼쪽 테두리 | 테두리 없는 연한 패널 + 정보 아이콘 |
| 마이크로카피 | 업로드 화면의 5줄 설명문 (읽히지 않는 안내문) | "업로드 한 번으로 받는 것" 4항목으로 바꾸고, 안전 문구는 한 줄 |
| 상호작용 상태 | focus-visible 링 없음 | 모든 포커스 가능 요소에 2중 링 |
| 상호작용 상태 | 버튼·단계 메뉴 높이 40px 미만 | 최소 44px (터치 기준) |
| 상호작용 상태 | 매칭 화면에 1차 행동이 둘 ("묶음 제안 보내기", "비용·탄소 비교") | 묶음 제안 발송은 승인 단계로 통합. 화면당 1차 행동 하나 |
| 상호작용 상태 | 최적안 카드 선택 불가 | 카드가 라디오처럼 선택되고 승인 버튼 문구와 문서 수량이 선택에 따라 바뀜 |
| 상태 디자인 | 단계 전환 시 로딩 상태 없음 | 식별 단계에 분석 진행 목록(4단계 체크)과 스켈레톤 |
| 길 찾기 (Trunk test) | 앞 단계에서 확정한 사실을 다음 화면에서 못 봄 | 제목 아래 "지금까지 확정" 칩 띠가 단계마다 누적 |
| 타이포그래피 | 본문 15px, 큰 숫자에 탭형 숫자 미적용 | 본문 16px, 금액·수량에 tabular-nums |
| 접근성 | 다크 모드 없음, 모션 감소 설정 미반영 | 팔레트 다크 값으로 다크 모드(자동·수동 전환), prefers-reduced-motion 시 애니메이션 제거 |
| 접근성 | 차트에 대체 텍스트 없음, 탭에 ARIA 없음 | 차트 role=img + aria-label, 탭·라디오그룹·다이얼로그 ARIA |
| 반응형 | 비교표가 좁은 화면에서 넘침, 지도에 반경 표시 없음 | 표 가로 스크롤 래퍼, 반경 2km 원과 라벨 |
| 반응형 | 모바일에서 가로 스크롤 메뉴가 그리드 열을 늘림 | 그리드 `minmax(0,1fr)`, 플렉스 자식 `min-width:0` |
| 반응형 | URL 해시가 섹션 id와 같아 앵커 스크롤 발생 | `#step-N` 형식으로 변경, `?theme=light|dark` 지원 |
| 키보드 | 단계 이동이 마우스 전용 | ← → 키로 단계 이동, Esc로 모달 닫기, 단계 이동 시 본문에 포커스 |

## 유지한 것

- 데이터 시각화 팔레트(파랑 #2a78d6, 빨강 #e34948)는 검증기를 통과한 값이라 그대로 두었다. 다크 모드 막대는 같은 hex를 쓰며 다크 표면에서 3:1 이상 대비를 유지한다.
- 숫자는 모두 시연용 가정값이다. 설문과 업체 인터뷰 결과로 교체해야 한다.
