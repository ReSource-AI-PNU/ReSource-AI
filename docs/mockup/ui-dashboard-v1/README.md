# 대시보드형 UI 시안 v1 (2026-11-22)

배출 기업 화면을 카드형 대시보드로 다시 짠 시안이다. **DESIGN.md를 바꾸는 제안이며 아직 팀 승인 전이다.**

## 여는 법

`index.html`을 브라우저로 열면 전체 화면 목록이 나온다. 화면 안의 메뉴·버튼을 누르면 다른 화면으로 넘어가고, 오른쪽 아래 "전체 화면 목록"으로 돌아온다. 링크 이동이 막히면 이 폴더에서 로컬 서버로 연다.

```
python -m http.server 8765
```

## 무엇이 들어 있나 (27쪽)

| 묶음 | 화면 |
|---|---|
| 찾기 | 결과 요약, AI끼리 나눈 대화, 계약 검토, 판단 표·근거 |
| 자료 | 폐기물 4개(스프루·런너, 불량 사출품, 포장 필름, 퍼지 덩어리), 보관장 3D 스캔, 폐기물 등록 1·2단계 |
| 승인·서류 | 승인 대기, 서류, 확정한 거래, 견적 요청서 |
| 실적 | 요약, 반출·검수 기록, 계획과 실제 비교, 인쇄용 리포트 |
| AI 신뢰도 | 평가 요약 |
| 버튼 뒤 화면 | 승인 확인 상자, 근거 패널, 지금 처리 단가 적기, 측정값 적기, 견적 요청서 메일 보내기, 3D 스캔 진행 |

## 값의 출처

모든 숫자와 문장은 배포된 체험하기(`/api/v3-demo`, 시연 회사 (주)한빛정밀)에서 2026-11-22에 받은 값이다. 시연용 가상 데이터이며, 체험하기 찾기를 다시 돌리면 값이 바뀔 수 있다.

- 찾기 결과: `GET /sessions/ses_109` (한 달 차이 +644,900원, 업체 3곳, 계약 검토가 (주)미소환경 건을 운반비 부담 미정으로 막음)
- 자료: `GET /orgs/org_hanbit/streams`, 3D 스캔: `GET /orgs/org_hanbit/scans`
- 실적·확정 거래: `GET /orgs/org_hanbit/report`, `GET /orgs/org_hanbit/memory`
- 견적 요청서: `GET /sessions/ses_109/quote-request`, 근거: `GET /evidence/{id}`
- AI 신뢰도: `GET /trust` (2026-11-19 AI 모델 평가)

열리는 화면이나 배포본 값이 없는 메뉴·버튼(같은 단지 후보, CSV 내려받기 등)은 시안에서 뺐다.

## DESIGN.md와 다른 점 (승인 필요)

- 카드형 대시보드와 넓은 본문 폭(지금 규칙: 여백과 가는 선, 본문 약 720px)
- 두 단 사이드바: 아이콘 레일 + 세부 메뉴(지금 규칙: 한 단 사이드바)
- 받는 돈 색을 파란색 `#2563EB`로(지금 규칙: 초록 `gain`)
- 서체는 시안 도구 제약으로 Pretendard 대신 Noto Sans KR을 썼다(앱에 적용할 때는 Pretendard).

색은 두 가지만 뜻을 가진다: 파란색은 받는 돈, 호박색(`warn`)은 확인이 필요한 곳. 나머지는 먹색과 회색이다.
