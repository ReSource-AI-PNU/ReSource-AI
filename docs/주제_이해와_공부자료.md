## 1. 대회가 묻는 것

대회 주제는 "산업현장의 **모든 기업**이 **AI를 활용하여** 폐기물과 부산물에서 **더 많은 경제적·환경적 가치**를 얻게 하라"이다. 대회는 이 주제를 6단계 파이프라인으로 구현하라고 요구한다. 각 단계는 아래 질문 하나에 답한다.

| 단계 | 답해야 하는 질문 |
|---|---|
| ① 식별·분류 | 이 폐기물은 무엇인가? |
| ② 가능성 판단 | 재활용할 수 있는가, 어디로 보낼 수 있는가? |
| ③ 규정 검토 | 법적으로 문제가 없는가? |
| ④ 업종·기업 탐색 | 누가 받아 주거나 함께할 수 있는가? |
| ⑤ 비용·탄소 비교 | 바꾸면 얼마나 이득인가? |
| ⑥ 최적안 제안 | 그래서 무엇을 해야 하는가? |

- 대회 공지의 품목은 폐플라스틱, 금속 스크랩, 폐목재, 포장재 네 가지다.
- 운영위원회가 가상 기업의 부산물 데이터를 제공한다.
- 대회 예시 서비스(사진으로 재활용 판정, 부산물 매칭, 단지 기업 추천, 비용·탄소 비교)는 대부분의 팀이 만들 것으로 본다. 그래서 차별화 기능을 따로 설계했다(설계안 v2 6.4절).

## 2. 우리 답

**정부가 한 해 10곳에만 해 주는 사업장 폐플라스틱 순환 진단을, AI 에이전트로 모든 중소 제조기업에 제공한다.**

### 누가, 언제, 무엇을 잃나

- **누가**: 부산·경남 고무·플라스틱 제조 중소기업(연 1,000톤 미만 배출)의 폐기물 담당자. 대부분 총무·생산·품질 담당이 겸직한다.
- **언제**: 처리업체가 단가 인상을 통보할 때, 연간 처리 계획을 세울 때, 원청이 탄소·재활용 데이터를 요구할 때.
- **무엇을 잃나**: 흐름마다 더 나은 경로(재투입, 매각, 묶음 매각, 열분해)가 있는데, 흐름을 구분하지 않고 혼합 소각으로 내보내 처리비, 원료 가치, 탄소를 함께 잃는다.

### 왜 이 주제인가

- **빈자리가 분명하다.** 정부가 2026년에 시작한 1:1 기술진단은 10곳뿐이고, 순환경제 지원사업은 연 1,000톤 이상 배출 기업만 신청할 수 있다. 두 제도가 닿지 않는 중소기업이 대상이다.
- **6단계를 억지로 만들 필요가 없다.** 정부 진단 절차(종류·성상 → 공정별 발생량 → 주변 재활용시설 여건 → 이행 방안)가 대회 6단계와 거의 그대로 겹친다.
- **결과가 크게 보인다.** 진단 단위를 "사진 한 장"에서 "공장의 흐름 여러 개"로 바꾸면, 결과물이 "이 더미의 등급"에서 "이 공장의 월 손익"으로 커진다.

### 6단계를 맡는 에이전트

| 단계 | 정부 진단 절차 | 에이전트가 하는 일 | 담당 트랙 |
|---|---|---|---|
| ① 식별·분류 | 종류·성상 | 흐름마다 재질, 단일 재질 여부, 오염, 출처(PIR·PCR) 판정 | A |
| ② 가능성 판단 | 공정별 발생량 | 흐름마다 갈 곳 다섯 가지 중 하나를 고르고, 발생량은 되묻는다 | B |
| ③ 규정 검토 | 이행 방안의 법적 요건 | 조항 인용이 붙은 체크리스트 | C |
| ④ 업종·기업 탐색 | 주변 재활용시설 여건 | 매각처·열분해 업체 탐색, 소량 흐름은 같은 단지 기업과 순회 수거로 묶기 | D |
| ⑤ 비용·탄소 비교 | 이행 방안의 효과 | 현행 "전부 소각" 대비 공장 시나리오 A·B·C·D의 손익과 회피 탄소 | B |
| ⑥ 최적안 제안 | 이행 방안 + 지원사업 연계 | 이행 계획서, 지원사업 신청 초안, 수거·견적 요청서. 외부 발송은 담당자 승인 후 | C |

차별화 기능 네 가지: **걸으며 진단**(공장을 돌며 말로 흐름 등록), **에이전트 실행 콘솔**(도구 호출과 근거를 시간순으로 표시), **에이전트 간 협상**(수거 업체 에이전트와 요일·단가 조율, 사람이 가드레일과 최종 승인), **재생원료 여권**(QR로 출처와 위·변조 여부 확인).

## 3. 핵심 개념

| 용어 | 뜻 | 왜 중요한가 |
|---|---|---|
| 흐름 (Stream) | 공장 한 곳의 폐플라스틱을 공정별로 나눈 단위 | 흐름마다 재질과 오염이 달라 갈 곳도 달라진다. 서비스의 진단 단위다 |
| 스프루·러너 | 사출 성형에서 녹은 수지가 금형으로 흘러가는 통로에 남아 굳은 플라스틱 | 재질이 단일하고 깨끗해 분쇄 후 재투입하기 쉽다 |
| 퍼지 | 사출기의 색이나 수지를 바꿀 때 실린더를 비우려고 밀어낸 덩어리 | 여러 수지와 색이 섞여 기계적 재활용이 어렵다 |
| PIR (Post-Industrial, pre-consumer) | 제조 공정에서 나온 부산물 | 국내외 재생원료 의무 규정은 대부분 PIR을 재생원료 실적으로 인정하지 않는다 |
| PCR (Post-Consumer) | 최종 사용자가 쓰고 버린 것 | 재생원료 의무가 인정하는 원료다. 공장이 원료를 받으며 쓰고 버린 포장 필름을 PCR로 볼 수 있는지가 우리 논리의 핵심이다 |
| 공정 재투입 (reuse) | 분쇄해서 같은 공정의 원료로 다시 섞는 것 | 신재 구매비를 줄인다 |
| 매각 (sell) | 재생원료 업체에 파는 것 | 처리비가 수익으로 바뀐다 |
| 단지 묶음 매각 (bundle) | 같은 단지에서 같은 재질 흐름을 내는 회사들과 순회 수거로 묶어 파는 것 | 혼자서는 트럭을 채우지 못하는 소량 흐름도 팔 수 있다 |
| 열분해 (pyrolysis) | 플라스틱을 산소 없이 가열해 기름(열분해유)으로 바꾸는 화학적 재활용 | 섞여서 기계적 재활용이 안 되는 흐름의 대안이다 |
| 순회 수거 | 각 회사가 같은 허가 업체와 따로 계약하고, 업체가 사업장을 차례로 도는 방식 | 공동 보관이 금지되어 있어서 묶음 수거의 기본값으로 정했다 |
| 트럭 적재율 | 품목별 차량 적재량 대비 실제 물량의 비율 | 단일 "최소 2톤" 기준 대신 쓴다. 필름은 무게보다 부피가 먼저 찬다 |
| 공동처리 신고 | 여러 사업장이 폐기물을 공동으로 처리하겠다고 지자체에 신고하는 것 | 선택 기능이다. 시행규칙 제21조제1항제9호(소량 배출 사업장) 경로로 초안만 만든다 |
| 올바로시스템 | 한국환경공단의 폐기물 인계·인수 전자 관리 시스템 | 사업장 폐기물의 배출부터 처리까지 기록한다. MVP에서는 연동하지 않는다 |

## 4. 시연 장면 한눈에 보기

녹산국가산업단지의 PP 사출 공장 (주)한빛정밀(가상)이 지금은 네 흐름을 모두 혼합 소각한다고 가정한다. **숫자는 모두 시연용 가정값이다.**

| 흐름 | 성질 | AI가 고른 경로 | 월 손익 (현행 → 적용) |
|---|---|---|---:|
| 스프루·러너 600kg | PP 단일, 깨끗함, PIR | 분쇄 후 공정 재투입 | −150,000원 → +510,000원 |
| 불량 성형품 400kg | PP, 라벨·금속 인서트 6%, PIR | 이물 제거 후 매각 | −100,000원 → +90,000원 |
| 퍼지·색 혼합 250kg | PP+ABS 혼합, PIR | 열분해 위탁 | −62,500원 → −20,000원 |
| 원자재 포장 필름 300kg | LDPE 스트레치 필름, PCR | 단지 3개사 순회 수거 후 매각 | −75,000원 → +15,000원 |
| **공장 합계 1,550kg** | | | **−387,500원 → +595,000원** |

- 발표의 절정은 공장의 월 손익이 흐름별로 나뉘면서 적자에서 흑자로 바뀌는 장면이다(월 +982,500원 개선).
- 포장 필름은 "킥 장면"이다. 한빛정밀 혼자서는 월 300kg이라 1톤 트럭 적재율이 30%에 그쳐 업체가 오지 않는다. 같은 단지의 두 회사와 묶으면 월 1,230kg, 적재율 123%가 된다.

## 5. 문제 정의 점검 (2026-11-13)

문제 정의 v2의 근거 10개와 5·6·7·11장의 주장을 원문으로 다시 확인하고, 심사위원이 던질 만한 반론을 조사했다. 웹 검색 한도 때문에 확인하지 못한 항목은 5.6에 따로 적었다. 이 장은 점검 결과만 기록하며, 문제 정의 v2와 설계안 v2는 고치지 않았다. 반영 여부는 팀이 정한다.

### 5.1 결론

- **방향은 맞다.** 정부 기술진단도 순환경제 DNA 지원사업과 같이 연 1,000톤 이상 배출 기업만 대상으로 한다. 두 제도가 모두 대량 배출 기업용이라는 사실이 확인되어, "빈자리" 논리는 오히려 강해졌다.
- **가장 위험한 곳은 시연 장면의 출발점이다.** "지금은 네 흐름 모두 소각한다"는 가정에서 월 개선액의 86.5%가 나오는데, 그중 깨끗한 스프루·러너와 불량품은 업계에서 이미 재투입하거나 파는 경우가 많다.
- **원인을 "정보 부재"로 단정한 부분이 약하다.** 재활용 시세는 공공기관이 매월 공개하고, 정부·언론은 수거체계와 비용을 원인으로 든다.
- **수치 몇 개는 보정이 필요하다.** 매립 단가, 열분해 반입비, 필름 매각 단가의 근거가 약하다(5.5).

### 5.4 약점과 보완 방향 (위험한 순서)

**약점 1. 시연의 출발점이 업계 관행과 어긋난다.**

- 시연은 "지금은 네 흐름 모두 소각"에서 출발한다. 월 개선액 982,500원 가운데 850,000원(86.5%)이 스프루·러너(+660,000원)와 불량 성형품(+190,000원)에서 나온다.
- 깨끗한 PP 러너를 분쇄해 재투입하는 것은 업계 통례이고(재생재 혼합 상한 20~25%), 사출 분쇄품과 불량품을 사는 시장도 있다. 신재 PP가 kg당 2,000원을 넘는 상황(2026.5)에서 이를 돈 내고 태운다는 가정은 업계 출신 심사위원이 바로 지적할 수 있다.
- 두 흐름을 이미 처리하고 있다면 개선액은 월 132,500원(연 159만 원)으로 줄어든다.
- ISO 14021은 같은 공정 안의 재투입을 재생 함량으로 치지 않는다. 따라서 재투입분은 협력사 리포트에서 재생 함량이 아니라 폐기물 감량으로만 보고할 수 있다.
- 보완 방향
  - 현행 상태를 "러너는 일부 재투입, 불량품은 고물상 매각, 나머지는 혼합 소각"처럼 현실에 가깝게 바꾼다.
  - 실제로 소각되는 흐름으로 개선액을 다시 만든다. 후보는 원자재 포장 필름·마대, 색과 재질이 섞인 퍼지, 원청 규격상 재투입이 막힌 러너, 혼합 재질 불량품이다.
  - 정부 진단 보도에서 노벨리스코리아가 "포장 필름 같은 폐합성수지 934톤을 전량 소각"한다고 나온다([브레스저널](https://breathjournal.com/article/782)). 이 사례는 킥 장면(포장 필름 묶음)의 근거로 쓸 수 있다.
  - 녹산 인터뷰(이슈 #3)와 설문(이슈 #1)의 첫 질문을 "어떤 흐름이 실제로 소각되는가"로 둔다.

**약점 2. "원인은 정보 부재"라는 인과가 약하다.**

- 한국환경공단은 재활용가능자원 가격을 매월 공개한다. 경남권 압축 PP는 2024~2026년 내내 플러스 시세였다(2026.10 390.5원/kg, [공공데이터포털](https://www.data.go.kr/data/3076421/fileData.do)).
- 환경일보(2026.1.18)는 사업장 폐플라스틱이 재활용되지 못하는 원인으로 "수거체계 미비와 처리비용"을 든다([기사](https://www.hkbs.co.kr/news/articleView.html?idxno=815586)).
- 보완 방향: 원인을 아래 세 가지로 다시 정의한다. "정보"의 범위를 시세가 아니라 3번으로 좁히면 근거 6과도 충돌하지 않는다.
  1. 소량·혼합 배출이라 수거 단위가 나오지 않는다(트럭 적재율, 차량당 요금).
  2. 흐름을 나누는 판단을 할 사람이 없다(근거 1).
  3. 내 흐름이 어느 업체의 허가 품목과 매입 조건에 맞는지 확인하는 비용이 크다.

**약점 3. 비슷한 서비스와 공공 플랫폼이 이미 있다.**

- SK에코플랜트 웨이블(481곳 사용, AI 배출량 예측과 감축 리포트), 리코(올바로 연동, 감축·자원화 SaaS), 한국환경공단 순환자원정보센터가 있다.
- 2026 스마트그린산단 통합공모의 "디지털 기반 자원순환 시범산단"(여수·포항)은 IoT 계측과 "유형별 최적 자원순환 솔루션"을 담은 플랫폼을 공공기관이나 비영리기관이 소유·운영하도록 정했다. 따라서 B2G로 "플랫폼을 판다"는 경로는 사실상 막혀 있다.
- 독일의 재생 플라스틱 거래 플랫폼 Cirplus는 2026.4에 영업을 중단했다. "매칭만으로는 사업이 지속되지 않는다"는 반박이 가능하다.
- 보완 방향
  - 차별점을 "흐름별 경로 선택(재투입·열분해 포함)"과 "PIR·PCR 출처 판정"으로 좁힌다. 조사한 유사 서비스 중 이 두 가지를 명시한 곳은 없었다.
  - B2G는 공공 플랫폼, 순환경제 DNA 컨설팅 수행사, 기술진단에 들어가는 "진단 엔진·용역"으로 다시 정의한다.

**약점 4. 열분해 경로는 아직 일반적인 경로가 아니다.**

- 사업장 폐플라스틱을 열분해 원료로 쓰는 것은 2026년에 규제특례 실증 과제로 승인된 단계다([전기신문](https://www.electimes.com/news/articleView.html?idxno=367649)). 지금 열분해 시설에는 주로 가정의 폐비닐이 들어간다.
- 반입비 80원은 EPR 선별품을 열분해 업체로 보낼 때 선별업체가 **받는** 지원금과 같은 숫자다. 열분해 업체가 원료를 사는 사례(폐비닐 약 48원/kg)도 있어서 돈이 어느 방향으로 흐르는지부터 불확실하다.
- PP와 ABS가 섞인 퍼지는 열분해 원료로도 불리하다(질소 불순물, 난연 ABS의 브롬).
- 보완 방향: 열분해 경로는 "실증특례 참여 업체에 한함"으로 표시하고, 반입비는 범위(업체 매입 ~ 배출자 부담)로 둔다.

**약점 5. 포장 필름의 PCR 논리는 국제 기준에서만 강하다.**

- ISO 14021은 "공장 등 시설이 최종 사용자로서 버린 재료"를 post-consumer로 정의한다. EU PPWR도 사용 후 폐기물을 가정 배출로 한정하지 않고, 부속서 II에 스트레치 필름이 있다. 국제 기준에서는 우리 논리가 성립한다.
- 한국에서는 재생원료 사용의무가 PET 병에만 있어서 LDPE 필름에 대한 제도상 수요가 아직 없다.
- 보완 방향: PCR 프리미엄을 손익에 넣지 않는 현재 방침을 유지한다. 가치의 근거는 EU에 수출하는 원청의 공급망 수요(PPWR 2030년 35%, ELV 2032년 15%)로 설명한다.
