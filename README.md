# Re:Source AI

**폐기물을 내보내는 회사와 받는 처리 업체를, 양쪽을 대변하는 두 AI 에이전트가 근거를 확인하며 연결합니다**

부산·경남의 사출 중소기업 겸직 담당자는 폐플라스틱 흐름마다 어디로 보낼 수 있는지, 그러려면 업체에 무엇을 확인해야 하는지 모릅니다. 처리 업체는 소량·혼합 물량의 품질과 조건을 확인하는 비용이 물량의 가치보다 커서 받지 않습니다. 그래서 가장 쉬운 혼합 소각이 기본값이 됩니다. Re:Source AI에서는 배출 기업과 처리 업체가 각자 자료를 올리면 회사 측 에이전트와 업체 측 에이전트가 대화해, 흐름마다 맞는 업체와 조건, 비용을 찾고 양쪽 승인 뒤 요청서와 이행 계획서를 만듭니다. 대화와 문서에 나오는 숫자와 법 조항은 근거 저장소에서 확인된 값만 씁니다. 설계는 [설계안 v3](docs/ReSource_AI_설계안_v3.md), 구현 상태는 [설계안 v3 구현 상태](docs/ReSource_AI_설계안_v3_구현_상태.md)에 있습니다.

## 대회 6단계와 두 에이전트

대회 6단계는 두 에이전트가 쓰는 판단 도구이고, 화면 맨 위에 진행 막대로 항상 보인다. 에이전트 메시지와 도구 호출은 모두 단계 값을 가진다.

| 단계 | 맡는 쪽 | 쓰는 도구 | 화면에 보이는 것 |
|---|---|---|---|
| ① 식별·분류 | 회사 측 | 탐지 모델, 등급 모델, 문서 추출, 출처 판정 | 흐름 카드마다 재질, 오염 등급, 출처(PIR·PCR), 탐지 박스 |
| ② 가능성 판단 | 회사 측 후보, 업체 측 수용 판단 | 경로 판단(조건부), 매입 기준 대조 | 흐름마다 경로 후보와 상태(확정, 조건부, 확인 필요), 막힌 조건 |
| ③ 규정 검토 | 양쪽 | 조항 검색, 허가 품목 대조 | 경로와 업체마다 요건 체크리스트와 조항 원문 |
| ④ 업종·기업 탐색 | 회사 측 | 업체 탐색(PostGIS, 허가·지역·기준 필터) | 후보 업체와 걸러진 업체(이유), 열린 대화 스레드 |
| ⑤ 비용·탄소 비교 | 양쪽 | 비용·탄소 계산, 업체 노선 계산 | 업체 제안별 월 손익, 운송비, 탄소, 현행 대비 |
| ⑥ 최적안 제안 | 회사 측, 양쪽 승인 | 흐름별 업체 배정 최적화, 문서 작성 | 최적안과 대안, 승인 상태, 요청서와 이행 계획서 |

## 기술 스택

- **에이전트**: 회사 측·업체 측 두 에이전트(A2A 대화), 판단 도구 MCP 서버. 모델 호출은 Microsoft Foundry(gpt-5-mini), 업체 측 오픈 모델은 Ollama. Agent Framework 어댑터는 선택 사항이다
- **근거 강제**: 근거 저장소와 근거 검증기. 모델은 숫자를 쓰지 않고 근거 ID만 고른다
- **백엔드**: FastAPI (Python). 배포는 Azure Container Apps가 기본이고, 공급자 등록 전에는 App Service로 대신한다
- **프런트엔드**: Next.js + React
- **데이터**: Azure Database for PostgreSQL (PostGIS, pgvector), Azure AI Search, Azure Blob Storage
- **문서·안전**: Azure AI Document Intelligence, Azure AI Content Safety (Prompt Shields)
- **모델**: Azure Machine Learning + MLflow, RT-DETR, ByteTrack, 등급 모델(측정값 CSV)
- **운영**: Entra ID, Application Insights + OpenTelemetry, GitHub Actions, Bicep

## MVP 범위 (대회 시연)

- 대상: 녹산산단 PP 사출 중소기업의 겸직 담당자. 압출·필름 공정은 비목표다
- 입력 세 경로: 사진·영상, 측정값 CSV(등급 모델), 문서(허가증, 매입 기준표, 원자재 명세)
- 시연 장면: (주)한빛정밀(가상)의 흐름 네 개(스프루·러너, 불량 성형품, 퍼지·색 혼합, 원자재 포장 필름)와 처리 업체 세 곳((주)새길자원, (주)남해열분해, (주)미소환경). 시연 숫자는 미리 정하지 않고 판단 도구가 근거 저장소의 값으로 계산한다
- 묶음 수거: 이웃 기업을 모으지 않는다. 업체 측 에이전트가 자기 노선 안에서 묶는다
- 승인: 양쪽 담당자가 승인해야 요청서와 이행 계획서가 나온다. 실제 계약, 실제 발송, 신고서 제출은 하지 않는다
- 재학습: 사람 교정과 업체의 실제 결과를 백그라운드에서 쌓고, 배포 게이트로 판단한다
- 뺀 것: 재생원료 여권, 걸으며 진단, 지원사업 신청서, 공동처리 신고서, 현장 지식 카드, 학습 콘솔, 명령창
