# Re:Source AI

**정부가 한 해 10곳에만 해 주는 사업장 폐플라스틱 순환 진단을, AI 에이전트로 모든 중소 제조기업에**

부산·경남의 고무·플라스틱 제조 중소기업은 공장에서 나오는 폐플라스틱 흐름의 성질과 갈 곳을 모른 채 "가장 싼 소각"을 기본값으로 내보냅니다. Re:Source AI는 공장의 폐플라스틱을 흐름별로 진단해 공정 재투입·매각·단지 내 묶음 매각·열분해·소각 중 갈 곳을 정하고, 규정 검토와 비용·탄소 비교를 거쳐 이행 계획서, 지원사업 신청 초안, 견적 요청서까지 만듭니다. 문제 정의와 근거는 [문제 정의 v2](docs/문제정의_v2.md)에 있습니다.

## 대회 6단계와 에이전트 매핑

단위는 사진 한 장이 아니라 공장의 폐플라스틱 흐름(Stream) 여러 개다. 정부 기술진단 절차와 대회 6단계를 겹친다.

| 단계 | 정부 진단 절차 | 에이전트 역할 (흐름 단위) | 핵심 기술 |
|---|---|---|---|
| ① 식별·분류 | 종류·성상 | 흐름마다 재질, 단일 재질 여부, 오염, 색 혼합과 출처(PIR 공정 부산물 / PCR 공장이 쓰고 버린 포장재) 판정 | Azure ML (RT-DETR + ByteTrack), Document Intelligence, Azure OpenAI |
| ② 가능성 판단 | 공정별 발생량 | 흐름마다 갈 곳 판정: 공정 재투입 / 매각 / 단지 묶음 매각 / 열분해 / 소각 불가피. 흐름별 발생량은 되묻는다 | 규칙 엔진, Fabric Lakehouse |
| ③ 규정 검토 | 이행 방안의 법적 요건 | 순환자원 지정 품목, PCR 출처 증빙, 단지 내 공동 수집·운반 요건, 위탁 업체 허가 범위, 지원사업 자격을 조항 인용과 함께 확인 | Azure AI Search (조항 단위 RAG) |
| ④ 업종·기업 탐색 | 주변 재활용시설 여건 | 매각처·열분해 업체 탐색, 양이 적은 흐름은 같은 단지 기업과 순회 수거로 묶고 트럭 적재율 표시 | PostgreSQL + PostGIS, OR-Tools |
| ⑤ 비용·탄소 비교 | 이행 방안의 효과 | 현행 "전부 소각" 대비 흐름별·공장 전체 손익과 회피 탄소, 공장 시나리오 A·B·C·D | Azure Maps Route API, 배출계수, KAU 시세 |
| ⑥ 최적안 제안 | 이행 방안 + 지원사업 연계 | 공장 이행 계획서, 정부 지원사업 신청 초안, 순회 수거 요청서, 매각 견적 요청서, (선택) 공동처리 신고서 초안. 외부 발송은 담당자 승인 후 | Azure OpenAI, Foundry 평가 |

## 기술 스택

- **에이전트**: Microsoft Foundry Agent Service + Microsoft Agent Framework
- **백엔드**: FastAPI (Python) on Azure Container Apps
- **프런트엔드**: Next.js + React
- **데이터**: Azure Database for PostgreSQL (PostGIS, pgvector), Microsoft Fabric, Azure Blob Storage
- **모델**: Azure Machine Learning + MLflow, RT-DETR, ByteTrack
- **운영**: Entra ID, Application Insights + OpenTelemetry, GitHub Actions, Bicep

## MVP 범위 (대회 시연)

- 입력: 세션 하나에 공장 흐름 여러 개(시연은 4개). 흐름마다 사진과 30초 이내 영상, 공정명, 월 발생량, 원자재 명세 PDF 선택
- 시연 장면: 녹산 PP 사출 공장 (주)한빛정밀(가상)의 네 흐름. 스프루·러너 → 분쇄 재투입, 불량 성형품 → 이물 제거 후 매각, 퍼지·색 혼합 → 열분해, 원자재 포장 필름(LDPE, PCR) → 단지 3개사 순회 수거(적재율 30% → 123%). 공장 월 손익 −387,500원 → +595,000원, 월 +982,500원 개선 (가정값)
- 품목: 폐플라스틱 중심으로 사출 공장 시나리오를 6단계·서류·승인·실제 결과까지 끝까지, 금속 스크랩·폐목재·골판지 포장재는 식별과 경로 판정까지
- 지역: 녹산 등 부산·경남 8개 산업단지에 가상 기업 100곳(녹산 30곳) 배치
- 묶음 수거: 순회 수거 계약이 기본값, 최소 물량은 품목별 변수와 트럭 적재율로 표시, 공동처리 신고는 선택
- 외부 발송: 담당자 승인 후 모의 업체 메일함
- 재학습 루프: 사람 수정(먹색)과 업체 실제 매입 결과를 정답 신호로 쓰고, 현장 지식 카드를 판정 근거로 인용
